# Bachelor's Degree in AIDA Repository

This is a personal collection of *projects* and *course notes* made during my Bachelor's Degree in Artificial Intelligence and Data Analytics, at the University of Trieste.

> **N.B.** Most of my lecture notes are written in Italian, with no intention to translate them into English.

## PROJECTS

[**Machine Learning (mod. B)**](./projects/MachineLearning/) - *SVD-Based Spectral Clustering (insert link!)*
- The Singular Value Decomposition (SVD) is one of the most important results in numerical linear algebra. In this work I reviewed a paper which describes an algorithm which applies the SVD to clustering problems. 
- The described algorithm is a variant of the Spectral Clustering method. 
- Reproduction of the main results of the paper, as well as tests on other datasets such as the two-moons dataset.

[**Computability, Complexity and Logic**](./projects/Logic/) - *Course timetabling with SAT Solvers*
- With the use of logic programming, in particular with Z3 SAT solver, I wrote a program which is able to create a course timetable which avoids conflicts in assigned time slots for the students, for the rooms and as well as for the teachers. 
- The data on the courses, teachers, classes and schedules and available rooms are handled with a SQL database, in particular with the SQLite variant.
- The program is meant to be used in any general context, so not only for high school courses, but as well as university courses, or courses of any other kind.

[**Complex Systems**](./projects/ComplexSystems/) - *Review and Implementation of a Predator-Prey Population Dynamic*
- In this project I have reviewed a paper about a generalization of the Lotka-Volterra population dynamics and implemented it, reproducing the main results of the reference paper and also extending it with periodic forcing, from which I observed chaotical phenomenons in the model.

[**Advanced and Parallel Programming**](./projects/AdvancedAndParallelProgramming/) - *Implementation of an Interpreter in C and of a Rendering Pipeline in Python*
- The project for this course consists of two separated modules.
- The first part is about the implementation of an intepreter for a custom programming language called "TensorForth"; mainly, the idea of TensorForth is to handle tensor operations efficiently with multithread programming.
- The second part is about the implementation of a retro-inspired rending pipeline in Python, making use of OOP concepts and efficient numerical computation with NumPy.
